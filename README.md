# SimpleCalculator

Simple Calculator using Python

About the Project

This is a beginner-friendly calculator application developed using Python. It performs basic mathematical operations.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
  

Technologies Used

- Python 3
- VS Code

Concepts Used

- Variables
- User Input
- Conditional Statements
- While Loop
- Break Statement

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the following command:

py Calculator.py
